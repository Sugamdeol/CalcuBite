# NutriScan AI - Neobrutalism Edition

## Features
- **Neobrutalism UI**: Bold, high-contrast, and modern design.
- **AI Food Analysis**: Powered by Pollinations AI (OpenAI-Large) for accurate nutritional data from images.
- **Personalized Goals**: AI-calculated daily limits based on your gender, age, weight, height, activity level, and health conditions.
- **Meal Logging**: Track Calories, Sugar, Protein, Carbs, Fats, Sodium, and Fiber.
- **Beautiful Dashboard**: Visual progress tracking and 7-day calorie trends.
- **Simple Auth**: Just pick a username and password. No OTP, no fuss.

## Tech Stack
- Frontend: Vanilla JS, CSS3 (Neobrutalism), HTML5
- Backend/DB: Supabase
- AI: Pollinations API (openai-large)
- Charts: Chart.js

## Development
The project uses a fresh Supabase database with the schema defined in `schema.sql`.
